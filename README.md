# Установка и управление AmneziaWG (Anti-DPI VPN) через Telegram-бота

Данный скрипт автоматизирует развертывание сервера **AmneziaWG** с поддержкой обфускации (защита от глубокого анализа трафика - DPI) и устанавливает Telegram-бота для выдачи доступов пользователям.

**Особенности скрипта:**
- Разработан для параллельной работы с обычным WireGuard на одном сервере (использует другой порт `51821` и другую подсеть `10.0.1.0/24`).
- Генерирует случайные параметры обфускации (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`, `H2`, `H3`, `H4`) для обхода блокировок.
- Изолированный Telegram-бот для управления именно подключениями AmneziaWG.

---

## 📋 1. Подготовка и Установка

1. Перенесите скрипт `amneziawg_install.sh` на ваш сервер (Ubuntu/Debian).
2. Создайте **нового** бота в Telegram через [@BotFather](https://t.me/BotFather), чтобы он не конфликтовал с ботом от обычного WireGuard. Сохраните выданный токен.
3. Узнайте свой Telegram User ID через бота [@userinfobot](https://t.me/userinfobot).
4. Запустите скрипт:
   ```bash
   chmod +x amneziawg_install.sh
   sudo ./amneziawg_install.sh
   ```
5. Следуйте инструкциям на экране (введите новый токен бота, ваш ID и желаемый промокод).

> 
> 🚀 Для получения доступа отправьте выданный вам ПРОМОКОД в этот чат.

### Краткое описание (About)
Отправьте `/setabouttext`, выберите вашего бота и отправьте:
> 🛡️ Бот для автоматической выдачи конфигов AmneziaWG VPN.

## 🎮 4. Как пользоваться ботом

### Для пользователей:
1. Пользователь запускает бота и отправляет промокод (например, `SUPERVPN`).
2. Бот мгновенно генерирует приватный конфиг с параметрами обфускации.
3. Бот присылает **QR-код** (для сканирования с телефона) и **.conf файл** (для импорта на ПК).
4. Пользователь открывает скачанное приложение AmneziaWG, нажимает "+" -> "Отсканировать QR-код" или "Импортировать из файла".

### Для администратора:
Напишите `/start` боту. Вам откроется панель управления со следующими кнопками:
- 📱 **Generate QR Code** - создать конфиг и QR-код для пользователя вручную (по имени).
- 📄 **Generate Config** - создать конфиг в виде файла.
- 📋 **List Clients** - посмотреть всех подключенных клиентов и их IP.
- 🗑️ **Delete Client** - удалить клиента (доступ будет моментально заблокирован).
- 📊 **Proxy Info / MTProto Link** - получить ссылку на MTProto Proxy для обхода блокировок Telegram.

## 🛠️ 5. Управление сервером и проверка статуса

Скрипт автоматически настраивает службы. В конце установки скрипт самостоятельно выполнит обязательную проверку статуса компонентов (AmneziaWG, MTProto, Telegram Bot, UFW и Sysctl).

**Проверка статуса вручную (если нужно убедиться, что всё работает):**
```bash
# Проверка AmneziaWG
sudo systemctl status awg-quick@awg0

# Проверка Telegram-бота
sudo systemctl status telegram-bot-awg

# Проверка прокси
sudo systemctl status mtproto

# Проверка фаервола
sudo ufw status
```

**Перезапуск AmneziaWG:**
```bash
sudo systemctl restart awg-quick@awg0
```

**Перезапуск Telegram-бота (AWG):**
```bash
sudo systemctl restart telegram-bot-awg
```

**Просмотр логов бота:**
```bash
tail -f /var/log/telegram-bot-awg.log
tail -f /var/log/telegram-bot-awg-error.log
```

## 🧹 6. Полное удаление и переустановка

Если вам нужно полностью удалить VPN со всеми конфигами пользователей, ботом и прокси (например, для чистой переустановки), используйте специальный скрипт:

```bash
sudo bash /opt/vpn/amneziawg_uninstall.sh
```
*Скрипт запросит подтверждение (5 секунд), после чего полностью очистит сервер от следов AmneziaWG.*

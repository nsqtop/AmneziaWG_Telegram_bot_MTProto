# 🚀 AmneziaWG (Anti-DPI) VPN + Telegram Bot + MTProto

Автоматизированный скрипт для развертывания собственного VPN-сервера с защитой от блокировок (DPI). Скрипт генерирует случайные параметры обфускации (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1`, `H2`, `H3`, `H4`) для маскировки трафика, разворачивает прокси для Telegram и удобную панель управления прямо в мессенджере.

## 🌟 Особенности и фичи

- **Абсолютный Anti-DPI:** Используется AmneziaWG в userspace (`amneziawg-go`) для защиты от Kernel Panic. Трафик маскируется под обычный UDP-шум и обходит ТСПУ.
- **Оптимизация для мобильных сетей:** Порт VPN изменен на UDP 443 (мимикрия под QUIC), а MTU снижен до 1200. Это решает проблему бесконечного "Ожидания рукопожатия" на LTE/3G.
- **MTProto Proxy в Docker:** Встроенный официальный прокси-сервер для Telegram. Развернут в Docker-контейнере на TCP 8443 для максимальной стабильности и предотвращения падений.
- **Telegram-бот для управления:** Генерация доступов в один клик. Не нужно заходить по SSH для добавления пользователей.
- **Система промокодов (Self-service):** Бот ежедневно генерирует промокод. Вы даете его друзьям — они сами получают настройки и инструкции. Поддерживается выдача нескольких конфигов одному пользователю (телефон + ПК).
- **Единые инструкции:** Пользователь получает красивое сообщение с QR-кодом, файлом конфигурации, ссылками на клиенты и ссылкой на прокси.
- **Health Check:** После установки скрипт автоматически проверяет статус всех компонентов системы.

## 🛠 Требования
- Чистый сервер с **Ubuntu 20.04 / 22.04 / 24.04**.
- Пользователь `root` (или права sudo).
- Токен Telegram-бота (получите у [@BotFather](https://t.me/BotFather)).
- Ваш Telegram ID (узнайте через [@userinfobot](https://t.me/userinfobot)).

## ⚙️ Установка (в 1 команду)

Скопируйте скрипт на сервер и запустите:

```bash
curl -O https://github.com/nsqtop/AmneziaWG_Telegram_bot_MTProto/main/awg_install.sh
sudo bash awg_install.sh
```

В процессе установки скрипт попросит вас ввести:
1. `TELEGRAM_BOT_TOKEN` — токен вашего бота.
2. `ADMIN_TELEGRAM_ID` — ваш ID (только вы будете иметь доступ к меню администратора).

После завершения установки вы увидите зеленый отчет **Health Check**. Перейдите в вашего бота и нажмите кнопку **Start**.

## 📱 Управление ботом

Меню администратора включает следующие функции:
- **📱 Generate Client (QR + File):** Создать нового пользователя вручную (введите имя, бот пришлет QR, `.conf` и инструкции).
- **📋 List Clients:** Посмотреть список всех активных клиентов (включая тех, кто зашел по промокоду).
- **🗑 Remove Client:** Удалить доступ у пользователя.
- **🔄 Show Promo Code:** Показать актуальный на сегодня промокод.

### 🎁 Как работают промокоды?
1. Каждые 24 часа бот генерирует новый 8-значный код и присылает его вам в личные сообщения.
2. Вы даете код другу. Он пишет этот код боту.
3. Бот присылает ему настройки и уведомляет вас: *«Новое использование промокода: @username»*.

## 🗑 Удаление и сброс

**Сброс пользователей:**
Если вы хотите удалить всех созданных пользователей, но оставить VPN и бота работать:
```bash
sudo bash /opt/vpn/clear_users.sh
```

**Полное удаление:**
Если вы хотите полностью удалить VPN, бота, Docker-контейнеры и очистить все настройки сервера:
```bash
curl -O https://github.com/nsqtop/AmneziaWG_Telegram_bot_MTProto/main/amneziawg_uninstall.sh
sudo bash amneziawg_uninstall.sh
```

## 🔧 Диагностика (если что-то пошло не так)

Скрипт настроен так, чтобы восстанавливаться после сбоев. Но если вам нужно проверить логи:

**Проверка статуса VPN:**
```bash
sudo systemctl status awg-quick@awg0
```

**Логи Telegram-бота:**
```bash
sudo systemctl status telegram-bot-awg
sudo journalctl -u telegram-bot-awg -n 50
```

**Логи MTProto (Docker):**
```bash
sudo docker ps | grep mtproxy
sudo docker logs mtproxy_mtproxy_1
```

> **Примечание:** Если после обновления ядра Linux VPN перестал работать (завис процесс `awg`), просто перезагрузите сервер командой `sudo reboot`.
